⚙️ Client MCP Configuration

Plug both Context7 and Playwright MCP directly into your favorite AI client.

{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": [
        "-y",
        "@upstash/context7-mcp@latest"
      ]
    },
    "playwright": {
      "command": "npx",
      "args": [
        "-y",
        "@playwright/mcp@latest"
      ]
    }
  }
}
💡 Tip: Once configured, restart Cursor, Claude Code, or Windsurf to activate both MCP servers automatically.
